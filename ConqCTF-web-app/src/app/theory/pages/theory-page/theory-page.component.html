Introduction

This platform is designed to help you learn cybersecurity through practical challenges known as Capture The Flag (CTF).

Each challenge presents a task where your goal is to discover a hidden value called a flag. A flag is a specific string (that include: ConqCTF{...}) that proves you have successfully solved the challenge.

Challenges are organized into different categories and difficulty levels, allowing you to start with easier problems and gradually improve your skills.

Learning Approach

This platform is designed for learning. It is completely normal to get stuck on a challenge.

  • 1. Take your time to understand the problem
  • 2. Try different approaches
  • 3. Use hints if needed
  • 4. Focus on understanding the solution, not just finding the answer

The goal is not only to solve challenges, but to develop a way of thinking that helps you approach security problems effectively.

How to Use the Platform

The platform is designed to provide a simple and consistent workflow for solving challenges. Understanding how it works will help you focus on solving problems instead of navigating the interface.

Opening a Challenge

Go to the Challenges page and select a challenge. When you click on a challenge, a dialog window will open with all the relevant information.

Reading the Description

The description is your starting point. It often contains important clues about what you need to do.

Read it carefully and think about what kind of problem it represents (for example: decoding, file analysis, or web interaction).

Working with Files

Some challenges include files that you can download. These files are often essential to solving the challenge.

  • 1. Click the download button next to a file
  • 2. Save it locally
  • 3. Analyze it using tools or manual inspection

Files may contain hidden information such as metadata, encoded data, or embedded content.

Using Hints

If hints are available, they are displayed as numbered buttons.

  • 1. Click a number to reveal a hint
  • 2. Click the same number again to hide it
  • 3. Only one hint is visible at a time

There is no penalty for using hints, so it is recommended to use them if you are stuck.

Submitting a Flag

Once you believe you have found the correct flag, enter it into the input field at the bottom of the challenge.

  • Ensure the format is correct (for example: ConqCTF{...})
  • Make sure there are no extra spaces
  • The value must match exactly

Understanding Feedback

After submitting a flag, the platform will respond immediately. Use this feedback to guide your next steps. Avoid guessing repeatedly without understanding the problem.

After Solving a Challenge

When a challenge is solved:

  • 1. It will be marked as solved in the interface
  • 2. You can move on to other challenges
  • 3. A challenge can be solved only once

Take time to understand how you solved the challenge. This is where the real learning happens.

Solving Workflow

Solving a CTF challenge is not about guessing the answer, but about following a structured way of thinking. This workflow will help you approach challenges step by step and avoid common mistakes.

Step 1: Understand the Problem

Start by carefully reading the challenge description.

  • 1. Identify what is given to you
  • 2. Look for keywords or unusual details
  • 3. Determine what the challenge is asking for

Step 2: Explore Everything

Do not assume anything is irrelevant. In CTF challenges, every detail may be important.

  • 1. Read the description again
  • 2. Check file names carefully
  • 3. Download all provided files
  • 4. Look for hidden or unusual data

Small details often lead to the solution.

Step 3: Start with Simple Techniques

Before trying complex tools, begin with basic checks.

  • 1. Open files normally
  • 2. Look for readable text
  • 3. Search for patterns (encoded strings, unusual characters)

Many beginner challenges are designed to be solved with simple observations.

Step 4: Form a Hypothesis

Based on what you observe, make an assumption about what might be happening.

  • 1. Is the data encoded?
  • 2. Is there something hidden in metadata?
  • 3. Is the challenge misleading you?

You do not need to be certain — just have a direction to test. Most of the time the description points you where to look or the hints.

Step 5: Test Your Approach

Try your idea using tools or manual methods.

  • 1. Decode strings
  • 2. Inspect files more deeply
  • 3. Use appropriate tools

If your approach does not work, that is normal. Adjust your idea and try again.

Step 6: Use Hints if Needed

If you are stuck, use the available hints.

  • 1. Hints are designed to guide you
  • 2. There is no penalty for using them
  • 3. They often point you in the right direction

It is better to learn with guidance than to remain stuck.

Step 7: Identify the Flag

Once you believe you have found the solution, check if it matches the expected flag format.

  • 1. Ensure the format is correct (e.g. ConqCTF{...})
  • 2. Check for missing or extra characters
  • 3. Make sure there are no spaces

Step 8: Submit and Learn

Submit the flag and observe the feedback.

  • 1. If correct, move on to the next challenge
  • 2. If incorrect, review your approach

Even after solving a challenge, take a moment to understand why the solution works. This is what builds your skills over time.

Key Idea

CTF challenges are designed to test your thinking, not your ability to guess.

A structured approach will help you solve problems more efficiently and improve your understanding of cybersecurity concepts.

Beginner Techniques

Many CTF challenges can be solved using a small set of fundamental techniques. As a beginner, you do not need advanced tools — understanding basic methods is often enough.

Inspect Everything Carefully

The most important habit in CTF is attention to detail.

  • 1. Read the challenge description more than once
  • 2. Look for unusual words, formats, or hints
  • 3. Check file names and extensions

Small details are often intentional and can lead directly to the solution.

Analyze Files

Files provided in challenges often contain the solution or a clue.

  • 1. Open files normally first
  • 2. Check for hidden content
  • 3. Look at metadata (information stored inside files)

For example, images may contain hidden text inside their metadata.

Look for Encoded Data

Many challenges use encoded strings instead of plain text.

  • 1. Base64 is very common
  • 2. Encoded text often looks like random characters
  • 3. Try decoding it using tools

If something looks unusual, it is worth testing.

Use Simple Tools

You do not need complex tools to get started. A few basic tools can solve many beginner challenges.

  • 1. Text editors for inspecting files
  • 2. Browser-based tools for decoding data
  • 3. Command-line tools for file analysis
  • 4. Tools like ExifTool for metadata inspection
  • 5. Tools like CyberChef for decoding data

Focus on understanding what the tool does, not just using it.

Search and Learn

It is completely normal to search for unfamiliar concepts.

  • 1. Look up unknown terms
  • 2. Read short explanations
  • 3. Try what you learn immediately

CTF learning is a combination of solving problems and researching new ideas.

Use Hints When Needed

Hints are part of the learning process.

  • 1. They guide you toward the correct direction
  • 2. They help you avoid frustration
  • 3. There is no penalty for using them

If you are stuck, using a hint is often the best next step.

Work Step by Step

Avoid trying random solutions. Instead, break the problem into smaller steps.

  • 1. Understand the problem
  • 2. Try one approach
  • 3. Evaluate the result
  • 4. Adjust your strategy

This structured approach is much more effective than guessing.

Key Idea

Most beginner challenges are not about advanced knowledge, but about using simple techniques correctly.

If you stay patient and methodical, you will be able to solve them.

Example Challenge

In this section, we will walk through a simple example to demonstrate how a CTF challenge can be solved using basic techniques. Let's try to solve challenge 'Image meta'. You can see it here.

Looking at the challenge it is of type forensics, so we immediately can think that there could be something inside the file that is hidden at first. Let's read the description to make sure what we have.

Alex send an image to Bob telling him it is just an image. Can you believe her or is there something else in the image?

Step 1: Understand the Clue

The description suggests that the image may contain hidden information. The phrase "just an image" is likely misleading and indicates that something is not visible at first glance.

Step 2: Inspect the File

After downloading the image, the first step is to analyze it.

  • 1. Open the image normally
  • 2. Look for anything unusual

If nothing obvious appears, the next step is to check the metadata of the image.

Step 3: Check Metadata

Images often contain metadata — hidden information such as title, author, or comments. Let's run the command exiftool camera.jpeg and look at what it gives us.

Using a metadata tool, you may find something unusual in the image, such as a long string:

Description : Q29ucUNURns0bHc0eTUtY2gzY2stbTM3NGQ0NzRfNzU

This does not look like a normal sentence, which suggests it might be encoded.

Step 4: Identify the Encoding

The string looks similar to Base64 encoding, which is commonly used in CTF challenges.

  • 1. It contains only letters, numbers, and symbols like =
  • 2. It has a structured pattern

This is a strong indication that the data should be decoded.

Step 5: Decode the Data

Using a decoding tool such as CyberChef, paste the string and apply Base64 decoding. After decoding, you will obtain a readable string — this is the flag.

Step 6: Submit the Flag

Copy the decoded value and paste it into the flag submission field in the challenge. If everything is correct, the platform will confirm that the flag is valid.

What This Challenge Teaches

Linux & Tools

While challenges are accessed through the platform, most of the actual solving happens on your own system. Using the right environment and tools will make your work much easier.

Why Use Linux

Many cybersecurity tools are designed for Linux systems. These tools are powerful, widely used, and often easier to use compared to alternatives on other operating systems.

  • 1. Better support for security tools
  • 2. Powerful command-line utilities
  • 3. Preferred environment for CTF players

Using Linux is not required, but it is strongly recommended for a smoother experience.

Kali Linux

Kali is a Linux distribution specifically designed for cybersecurity and penetration testing. It comes preinstalled with many useful tools, so you do not need to install them manually. This makes it a great choice for beginners.

Using a Virtual Machine

If you are using Windows or another operating system, you do not need a separate computer to use Linux. You can run Linux inside a virtual machine using software such as VirtualBox.

  • 1. Install VirtualBox on your system
  • 2. Download a Kali Linux image
  • 3. Run Kali inside the virtual machine

This allows you to safely use Linux tools without modifying your main system.

Basic Tools to Know

You do not need many tools to get started. A few basic ones can solve a large number of beginner challenges.

  • Metadata tools - for inspecting hidden information in files (for example images)
  • Decoding tools - for converting encoded data into readable text
  • Text editors - for manually inspecting files and data

For example, tools like exiftool can reveal hidden data inside files, while tools like base64 can decode encoded strings.

How This Connects to Challenges

When you download files from a challenge, you will often:

  • 1. Open them in your system
  • 2. Inspect their contents
  • 3. Use tools to analyze hidden data

Many solutions are found by combining simple tools with careful observation.

Key Idea

The platform provides the challenges, but your system provides the tools. Setting up a proper environment will make solving challenges easier and help you focus on learning instead of technical limitations.

Common Mistakes

When starting with CTF challenges, it is common to make certain mistakes. Recognizing them early will help you improve faster and avoid unnecessary frustration.

Ignoring Small Details

Many challenges rely on subtle clues hidden in the description, file names, or data.

  • 1. Overlooking a single word can block your progress
  • 2. Hidden hints are often easy to miss

Always take time to carefully read and review all available information.

Not Downloading or Inspecting Files

Files are often the most important part of a challenge.

  • 1. Some users try to solve challenges without downloading files
  • 2. Important data may only exist inside the file

Always download and analyze every provided file.

Guessing the Flag

Submitting random guesses is not an effective strategy.

  • 1. Flags must match exactly
  • 2. There is no partial correctness

Instead of guessing, focus on understanding the problem and finding a logical solution.

Ignoring Hints

Some users avoid using hints even when they are stuck.

  • 1. Hints are designed to guide you
  • 2. There is no penalty for using them

Using hints is part of the learning process and can help you progress more efficiently.

Overcomplicating the Problem

Beginners often assume that challenges require complex solutions.

  • 1. Many challenges are intentionally simple
  • 2. The solution may be straightforward once you notice the key detail

Start with simple approaches before trying advanced techniques.

Not Verifying the Flag Format

Even if you find the correct value, submitting it incorrectly will result in failure.

  • 1. Check the expected format (e.g. ConqCTF{...})
  • 2. Remove extra spaces
  • 3. Ensure all characters are correct

Giving Up Too Quickly

Getting stuck is a normal part of solving challenges.

  • 1. Take a break and return later
  • 2. Re-read the description
  • 3. Try a different approach

Persistence is an important skill in cybersecurity.

Key Idea

Mistakes are part of the learning process. Each challenge you attempt helps you improve your problem-solving skills.

Focus on understanding why something works or does not work — this is what leads to real progress.
